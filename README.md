## 🚀 Featured Projects

### [MarketPulse Streaming](https://github.com/Nganga7/MarketPulse-Streaming)
Real-time market data pipeline ingesting three live Binance products through
**Airflow → PostgreSQL**, published to **Kafka** with Avro + Schema Registry,
and consumed by **Spark Structured Streaming** into **Cassandra**.

- Schema-governed streaming with controlled schema evolution
- Three concurrent streaming queries with independent checkpoints
- Fault-tolerant batch + streaming architecture

### Batch Analytics Pipeline (BigQuery + dbt + Docker) *(in progress)*
Containerized ingestion with **Docker**, orchestrated by **Airflow**, loaded into
**BigQuery**, transformed with **dbt** (staging + marts, with tests), and served
through a **Looker Studio** dashboard.
